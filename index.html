스테이지 선택

카드를 옆으로 밀거나 화살표로 넘기면서 골라보세요. 이미 깬 장은 다시 놀 수 있고, 장은 순서대로 열려요 — 한 장을 클리어하면 다음 장이 열리고, 아직 잠긴 장은 로 표시돼요.

비밀 스테이지 21장은 조합 59가지를 모두 찾으면 이곳에도 나타나요.

합성 미리보기

「단어+단어」로 입력하면 새 단어가 태어나요. 숨은 조합은 전부 59가지.

비 + 태양 = 무지개 물 + 불 = 증기 모래 + 불 = 유리 철 + 불 = 검 빵 + 치즈 = 샌드위치

연쇄 합성 연구소

합성으로 만든 단어가, 다시 다음 합성의 재료가 돼요. 한 번에 끝나지 않는 3단 연쇄를 완성해 보세요.

물 + 불 = 증기→ 증기 + 바람 = 구름→ 구름 + 물 = 비→ 비 + 태양 = 무지개
물 + 흙 = 진흙→ 진흙 + 불 = 도자기· 진흙 + 태양 = 벽돌→ 벽돌 + 벽돌 = 집
조합을 찾을수록 연금술사 랭크가 올라요 — 견습부터 대연금술사까지 6단계. 조합 59가지를 모두 찾으면 21장 비밀 스테이지 「처음 단어의 방」이 열리고, 처음 만들 때마다 최초 발견 배지와 보너스 점수가 붙어요.

무한 합성은 게임 화면 위쪽 탭에서도 언제든 열 수 있어요 — 모험 · 연구소 · 무한 합성 세 탭 중 맨 오른쪽이에요.
